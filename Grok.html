Lumo genera un único archivo HTML. Puedes publicarlo gratis en varios sitios:

          
    
            
  1. Netlify Drop — Arrastra el archivo .html a app.netlify.com/drop.
    2. 
            
  2. GitHub Pages — Sube el archivo a un repositorio y activa Pages.
    3. 
            
  3. Cloudflare Pages / Vercel — Sube el proyecto o el archivo único.
    4. 
            
  4. Surge.sh — npx surge desde la carpeta del archivo.
    5. 
          

          
Las claves API se guardan solo en tu navegador (localStorage). No se envían a ningún servidor de Lumo. No las compartas en enlaces.

        

        

          
          
En Safari (iPhone): Comparte → «Añadir a pantalla de inicio». En Chrome/Android: menú → «Instalar aplicación» o «Añadir a pantalla de inicio».

          
        

        

          
          
Ctrl/Cmd + Enter — Generar · Deshacer recupera la versión anterior · El historial guarda las últimas páginas.
